# Service: AI Integration

**Load when the brief is about adding LLM or AI features to an existing product**

---

## What it is

Corvane engineers add AI features (search, summarisation, assistants, classification, document processing) to a client's existing product. Every engagement starts with an evaluation suite: a set of real test cases that defines what "working" means before any feature code is written.

## Who it's for

Product teams under pressure to ship AI features who haven't done it before, and CTOs who don't want to ship something that confidently gives customers wrong answers.

## How it works

1. **Use-case workshop:** which AI feature, for which user, measured how.
2. **Evaluation suite first:** 200 to 2,000 test cases from real data, agreed with the client.
3. **Prototype against the suite:** model choice, prompting, retrieval, compared on the same tests.
4. **Ship behind a flag:** with monitoring and a feedback loop.
5. **Handover:** the client keeps the evaluation suite and can test every future change against it.

## Key messages

- We define "working" before we build.
- You get evidence, not a demo that works on the presenter's laptop.
- You keep the evaluation suite. Every future model or prompt change can be tested against it.

## Proof to use

Mendwell Health: AI triage feature shipped in 10 weeks with an evaluation suite of 1,200 test cases.

## Never say

- That AI will replace the client's engineers or staff
- Accuracy numbers that aren't from an approved case study
- "AI-powered" (banned)
