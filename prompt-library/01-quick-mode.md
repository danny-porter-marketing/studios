# Quick Mode

**About 5 minutes · One short asset**

---

## When to use

Subject lines, headlines, CTAs, a reply to a prospect, one paragraph, an ad hook. Anything under about 80 words.

## What to load

1. `CLAUDE.md`
2. `brand-guidelines/BRAND.md`
3. `messaging-guidelines/MESSAGING.md`
4. `use-cases.md`
5. The persona file for the reader

## Steps

1. Check the brief has all five fields. Ask once for anything missing.
2. Write one output.
3. Run the four-pillar audit. Fix anything under 90.
4. Present the output first, then the score in four lines.

## Output format

```
[The asset]

Brand 24/25 · Messaging 23/25 · Persona 24/25 · Craft 23/25 = 94
Weakest: messaging. [One sentence on why.]
```

For subject lines and headlines, give 3 options unless the brief asks for one, each scored together.
