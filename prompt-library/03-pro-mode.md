# Pro Mode

**30 minutes or more · Three directions, scored, operator picks**

---

## When to use

High-stakes assets: a new campaign's flagship landing page, a launch post, a strategic account's first email, a new positioning line. Anything where range matters more than speed.

## What to load

Everything in Pattern Mode, plus all three files in `lineage/`.

## Steps

1. Check the brief.
2. Write three complete versions, one per creative director: Editor, Provocateur, Architect. Each must be genuinely different in structure and angle, not the same draft in three tones.
3. Score each with the four-pillar audit.
4. Give a verdict: which one you'd ship for this reader and why, in 3 sentences. No "they're all great".
5. Name what you'd borrow from the losing versions, if anything.
6. Wait for the operator to pick before running reviewers or tools.

## Output format

```
VERSION A · The Editor
[asset]
Brand 24 · Messaging 23 · Persona 24 · Craft 22 = 93

VERSION B · The Provocateur
[asset]
Brand 22 · Messaging 22 · Persona 21 · Craft 23 = 88

VERSION C · The Architect
[asset]
Brand 24 · Messaging 24 · Persona 22 · Craft 24 = 94

Verdict: C. [Why, in 3 sentences.]
Borrow: the hook from B.
```
