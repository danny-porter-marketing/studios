# LinkedIn post

## 1. Brief
Need: author (Marta or Piotr), post type, the source moment or idea, the one point. If the operator only gives a topic, propose 3 angles (one per post type that fits) and let them pick before writing.

## 2. Load
- `CLAUDE.md`, `BRAND.md`, `MESSAGING.md`, `use-cases.md`
- `messaging-guidelines/voices/marta-linkedin.md` or `piotr-linkedin.md`
- `craft-guidelines/linkedin-post.md`
- The persona file for the intended audience

## 3. Write
Shape from the craft guide. Hook first, and test it alone: would it stop the target reader scrolling? Write 3 hook options, pick the strongest, and show the other two under the post.

## 4. Check the Corvane ratio
Check the last posts in `campaigns/social/` if they exist. If Corvane was mentioned in any of the last three posts by this author, keep this one Corvane-free.

## 5. Audit
Four-pillar audit. Brand pillar includes: no emoji, no hashtag strings, no em dashes, no "Agree?" endings.

## 6. Save and report
Save to `campaigns/social/<yyyy-mm-dd>-<author>-<slug>.md`. Report the post, alternative hooks, score.
