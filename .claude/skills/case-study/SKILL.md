# Case study

## 1. Gather facts
From the brief and the operator's source material: client, industry, service, timeline, stakes, approach, outcomes, any supplied quote. Check the client is on the approved list in MESSAGING.md. If not, stop and ask whether the client has approved being named.

## 2. Separate facts from claims
Make a short table before writing:

```
Fact | Source (MESSAGING.md / operator) | Approved for public use? (Y/N)
```

Anything not approved gets flagged, not written.

## 3. Load
`CLAUDE.md`, `BRAND.md`, `MESSAGING.md`, the reader's persona and voice, the industry and service files, `craft-guidelines/case-study.md`.

## 4. Write
Full case study (eight sections) or short proof story, per the brief. Show the client in charge. Never write a quote; include one only if the operator supplied it word for word.

## 5. Audit
Four-pillar audit. Messaging pillar fails automatically if any number lacks a source.

## 6. Report
The asset, the fact table, the score, and a list of any new numbers that should be added to MESSAGING.md once approved.
